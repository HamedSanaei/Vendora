# Product-card purchase row — Penpot handoff

Implemented on 2026-10-25. No production deployment, push, API, product-price, stock-data or dependency changes.

## Implementation

- All active home sections, shop/catalog, search, category, related products, account wishlist and its recommendations use the existing `CatalogProductCard`.
- One small `ProductCardPurchase` shares the price/action markup between that card and the retained TypeScript compatibility `ProductCard`. It does not introduce a second product card or cart implementation.
- Removed the CSS column switch below 230px. RTL price stays right and the square stays left at every container width; English mirrors naturally.
- Visual square: 40px below 200px card-content width, 44px above; actual button target always 44px. Mobile SVG viewport is 28px and centered; larger SVG is 24px. Existing Jade tokens, icon, focus ring, typography, images, borders and card minimum heights remain.
- Explicit pixel padding avoids Bootstrap's conflicting `p-3/p-4 !important` rules.
- Price shrinks within its own container for unusually large values. Old price stays above current price. Narrow cards use V3's number-only presentation; full price/currency remains in accessible text. No monetary value or formatting source changed.
- User-approved in-cart behavior: square shows actual quantity, opens the existing `QuantityStepper` in a small anchored Popper portal. Escape/manual close restores focus; outside pointer/focus dismisses; last-unit removal closes. Stock-limit feedback and cart toasts remain in the existing Redux listener.
- Existing add/increment/decrement callbacks and localStorage persistence are reused. Recommendations now also display actual shared cart quantities.
- Synchronous Redux operations do not invent an asynchronous loading state. Existing catalog loading skeletons and out-of-stock disabled actions remain.
- Header wishlist summary, Mini Cart, cart page and product purchase panel keep their separate existing designs. Unrouted legacy Harri JS cards remain unchanged.

## Changed code

- `site/src/components/vendora/product/product-card-purchase.tsx`: shared row, quantity badge and existing stepper popover.
- `site/src/components/vendora/catalog/catalog-product-card.tsx`: reuse row and fix padding collision.
- `site/src/components/vendora/product/product-card.tsx`: retained compatibility card reuses the same row instead of a full-width bar.
- `site/src/components/vendora/account/wallet-content.tsx`: recommendation quantity synchronization.
- `site/src/app/vendora.css`: stable horizontal layout, square/glyph sizing, numeric fitting and scoped popover styles.
- `site/scripts/check-product-card-layouts.cjs`: isolated browser regression using synthetic local API/session fixtures only.
- `docs/product-card-penpot-changes.json`: machine-readable exact IDs, before dimensions and final geometry/archive checks.

## Penpot scope

70 existing card components/instances were corrected in place: 4 shared, 24 homepage, 34 V3 shop/detail/inventory and 8 wishlist cards. No new pages, frames or reusable components were created. All card widths/heights were retained. Five archived V2 boards were compared recursively and are unchanged.

Changes set right-price/left-square geometry and bottom/inline constraints, center the existing glyphs, fix the overflowing shared-mobile label and resize the visible V3 mobile bag glyph from 24px to 28px within its 40px button. Legacy hidden plus glyphs remain hidden when a bag icon is present.

Two temporary SVG imports were discarded using Penpot's instance-delete behavior (hidden instance layers); they are recorded in the JSON journal and have no visible effect. No navigation component was detached or replaced.
